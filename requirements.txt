# SmartCrawler 依赖
# ---------------------------------------------------
# 唯一必需依赖：PySide6 已包含 QtWidgets / QtWebEngine / QtNetwork
PySide6>=6.6.0

# -------------------------------------------------------------------
# 可选依赖：Scrapling 融合层
# -------------------------------------------------------------------
# 不装也能正常使用：程序会自动降级为纯浏览器引擎，
# 界面上「抓取引擎」的非浏览器选项会在抓取时提示并回退。
#
# 装上后解锁四项能力：
#   · HTTP 快速模式    curl_cffi 伪装浏览器 TLS 指纹，不开浏览器，静态页最快
#   · 隐身引擎         可自动过 Cloudflare 验证
#   · 动态引擎         Playwright，适合 JS 渲染重的页面
#   · 自适应选择器     网站改版后依据元素特征自动重新定位（自愈）
#
# 安装（本项目 venv 是 --without-pip 建的，用系统 pip 指定目标解释器）：
#   ⚠️ --python 必须放在 install **之前**，否则 pip 报
#      "The --python option must be placed before the pip subcommand name"
#
#   python -m pip --python "<项目>\.venv\Scripts\python.exe" install "scrapling[all]"
#   <项目>\.venv\Scripts\scrapling.exe install      # 仅隐身/动态引擎需要
#
# 免安装版（exe 不看 .venv，要把包装进它的外挂依赖目录）：
#   python -m pip install --target "<解压目录>\SmartCrawler\crawler_data\site-packages" "scrapling[all]"
#   必须是 Python 3.13（与打包用的解释器同版本），否则 curl_cffi / greenlet
#   这类带 C 扩展的包无法导入。
#
# 注意：
#   · 第二条会下载 stealth 浏览器（数百 MB），仅当要用隐身/动态引擎时才需要；
#     HTTP 快速模式与自适应选择器**不需要**执行它。
#   · 浏览器默认下到用户目录，若被安全软件拦截（EPERM），可先设
#     PLAYWRIGHT_BROWSERS_PATH 指到非系统盘，并把该目录加入杀软白名单。
#   · 打包发布时建议不包含 scrapling：playwright / camoufox 会把产物撑大数百 MB，
#     而未安装时的降级路径已由 tests/test_scrapling.py 覆盖。
#
# 说明：
#   · QWebEngine 从 6.6 起自带 Chromium 124+
#   · 若 pip 安装体积过大，可用：
#       pip install PySide6-Essentials PySide6-Addons
#     并确保 Addons 包含 QtWebEngineCore / QtWebEngineWidgets
